# 护栏穿模修复

2026-09-05。用户反馈赛车与墙壁穿模，实际浏览器可稳定复现。

## 原因与修正

旧碰撞只把车身中心限制在赛道横向约 11.15 米处，未计入车头、尾翼、轮胎和旋转后的宽度。原护栏又由分离的 6.7 米长盒子组成，和碰撞规则没有共用几何；车辆之间的推挤发生在护栏修正之后。

- 三款实际 GLB 在前轮最大转向、车身最大侧倾时，横向范围约 ±1.506m，纵向 -2.300 至 +2.485m。新旋转碰撞矩形覆盖 ±1.54m、车头 2.53m、车尾 2.34m。
- 渲染和碰撞共用 `barriers.ts` 中的连续护栏四边形，每一节与下一节共享端点，包含弯道和起终点接缝。
- 使用分离轴检测整车与护栏的交叠，向赛道内侧消除穿透并消除朝墙外的速度。玩家、AI、护盾状态使用相同边界。
- 车辆碰撞后立即重新处理护栏，防止对手将车挤到墙外；修正后再计算车身位置与圈进度。
- 起终点拱门支柱移动到护栏外侧，避免成为没有碰撞的赛道内障碍。
- 速度表采用实际平面位移速度，撞墙时不把引擎的目标速度显示为车速。逆行与擦碰提示错开位置。

## 补充试玩

- 桌面 1440×1000，流星 R3：实际使用一次氮气，按住 Shift + 右转漂移并顶墙。35 次 HUD 采样的整车到墙最小距离为 0.000m（保留三位小数），接触稳定时 0.055m；车辆模型比碰撞矩形更小。切换近/远两档镜头，未见车体穿透护栏。反向打方向后继续前进，进度从 19.99m 到 41.95m，回正次数为 0。
- 手机视口 390×844，潮汐 R2：通过浏览器 CDP 触屏协议同时按住左转和漂移。30 次采样最小距离 0.014m，截图后采样为 0.010m，车身在墙内侧；页面无横向溢出。
- 测试设备实测约 119–133 FPS，没有阻断控制台错误。手机流程为浏览器双触点模拟，未覆盖物理手机硬件。
- 没有向运行中的浏览器注入位置、时钟、生命、物品或检查点。

最终界面复查：实际滑行速度 7.49m/s 对应速度表 27km/h；逆行提示底部 y=384.09，擦碰提示顶部 y=430.80，彼此不重叠。手机终稿接触距离 0.055m。
