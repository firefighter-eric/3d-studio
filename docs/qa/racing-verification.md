## 左右转向修正补验

用户试玩指出左右反转。原先输入测试只验证数值变化，错误地把右键对应航向角增加作为预期。模型以 +Z 为前方、相机从车尾跟随，因此驾驶员右方是局部 -X，右转必须减小 Three.js 的 rotation.y。

已同时修正驾驶物理、AI/辅助转向的目标角换算和前轮转向动画。新回归测试在四个不同车头朝向下，使用真实 PerspectiveCamera 投影比较左、直行、右三个结果，验证的是屏幕方向。

修正后重新加载实际浏览器，竞速挑战、手动油门，由静止加速后操作。相对开始转向时的车身右方向，位移实测如下（正数向右，负数向左）：

| 左方向键 | -1.365 |
| 右方向键 | +1.994 |
| A | -1.434 |

| 手机油门 + 左转双触点 | -1.604 |
