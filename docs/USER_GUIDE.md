# 使用指南

[文档总览](README.md) · [启动方法](DEVELOPMENT.md) · [资产来源](ASSETS.md)

打开 [在线站点](https://3d-studio-hazel.vercel.app/)，或启动当前工作树后使用 [本地站点](http://localhost:5180/)。下面的 `/#...` 表示站点地址后的路径；线上可见内容以实际部署为准。

## 找到与查看模型

「模型」默认展示全部收录内容。可以输入中文、英文、型号或别名，再组合品牌、类型、来源与排序。例如：

| 想找什么 | 操作 |
| --- | --- |
| 苹果与 NVIDIA 的电脑 | 搜索「电脑」，或选择类型「电脑」 |
| 大疆无人机 | 品牌「DJI」+ 类型「无人机」 |
| NVIDIA 机柜 | 搜索「NV72」或「NVL72」 |
| GTX 1080 Ti / RTX 5090 | 搜索「1080Ti」「5090」；可再选 NVIDIA + GPU |
| DGX Spark / Station | 搜索完整名称；「NV Studio」在本库作为 Station 别名 |
| Xbox 与 PS5 | 类型「游戏主机」；搜索「Xbox Series X」可区分 X / S |
| 特斯拉产品 | 搜索「特斯拉」或选 Tesla，再按汽车、机器人、储能设备、充电桩筛选 |
| 猎鹰重型 | 搜索「重型猎鹰」「猎鹰重型」「Falcon Heavy」或「双助推器」 |

多个空格分隔词需要分别命中。无结果时先清除多余筛选。筛选与排序写在地址中，可复制分享；从详情点「返回模型库」会在当前会话恢复筛选、滚动与上次卡片焦点。

点击卡片的预览或「查看模型」进入详情。拖动旋转、滚轮缩放、右键平移；手机可以双指缩放和调整视角。画布工具栏也提供旋转、缩放、恢复和自动环绕，支持键盘操作。观察航天模型可选择全貌、上面级或发动机，并切换「分级展开」。DJI 的部分产品可切换折叠、展开或配件构型。

卡片上的来源含义：

| 标签 | 意义 |
| --- | --- |
| 官网展示 | 由品牌公开展示模型转换或整理，来源与权利归属见详情 |
| 外观重建 | 项目依据公开资料建模，局部细节与尺寸可能近似 |
| 原创设计 | 项目原创的模型造型 |

下载按钮只在有 GLB 文件时出现。DJI 下载当前构型；航天分级展开只是查看状态，下载仍是完整组合体。网页中的大小是展示比例，下载文件保留记录的坐标单位；这些产品展示模型不作为测量或加工依据。

## 选择与组合场景

在卡片或详情勾选「选为创作素材」，可以跨品牌选择；改变搜索条件不会清空选择。然后加入发射基地，或进入「场景」→「静海发射基地」继续选择。

基地初始有 16 个实例，最多新增 12 个；新增模型按预设位置排在前方。剩余空间不足时只加入可容纳的数量，提示会说明结果。详情中的「加入发射基地」直接加入当前模型；批量操作加入本次选择，完成后清空选择集合。

「撤销上一个」删除最近新增实例，「清空新增」只清除新增部分，基础基地保留。新增布局在当前浏览器自动保存，刷新仍可恢复。当前没有任意拖拽、旋转编辑、场景 GLB 导出或跨设备云同步。

DJI 加入场景使用默认构型，详情中暂时选择的构型不随实例保存。Tesla 车辆作为展品，不会自动变成《湛蓝大奖赛》的驾驶车型。

## 看回收动画与下载短片

从「动画」选择主题，也可从对应航天模型详情进入。

| 主题 | 入口与操作差异 |
| --- | --- |
| 星舰：发射与回收 | `/#animations/starship-recovery`；导演节奏 / 1× / 4× / 8×；导演 / 自由跟随 / 塔架 / 特写 |
| 猎鹰重型：双芯归来 | `/#animations/falcon-heavy-recovery`；0.5× / 1× / 2×；导演 / 双芯全景 / LZ-1 / LZ-2 特写 |

等待三维场景就绪后播放。可暂停、倒拖进度、点阶段跳转、回到起点或全屏；空格播放 / 暂停，左右方向键前后 5 秒，Home 回到起点。正在操作按钮、下拉框或时间滑块时，快捷键遵循控件自身行为。切换后台自动暂停，两套演示均无音轨。

猎鹰重型演示长 56 秒，可选择导演镜头、双芯全景或两枚助推器各自的特写，并以 0.5× 慢放观察着陆。两套演示都在浏览器中实时渲染，网站不提供 MP4 播放或下载；本地成片制作见 [动画与视频](ANIMATIONS.md)。

两枚侧助推器分别落地，中央芯级继续上升；星舰演示则是助推器返回塔架。轨迹、场地和时间为视觉重建，参考及详细范围可在页面的重建说明或 [动画文档](ANIMATIONS.md) 中查看。

## 湛蓝大奖赛

进入 `/#games/azure-circuit`，选择赤焰 R1、潮汐 R2 或流星 R3，点击「驶向发车线」。默认自动油门；「轻松巡航」带辅助转向，「竞速挑战」由玩家自主转向。玩家与五名 AI 在 954 米原创海滨环线上完成三圈。

| 操作 | 键盘 / 触屏 |
| --- | --- |
| 转向 | A / D 或左右方向键；手机左右按钮 |
| 油门 / 刹车 | W / ↑、S / ↓；关闭自动油门后显示手机油门按钮 |
| 漂移 | 按住 Shift 并转弯；手机可同时按转向与漂移 |
| 氮气 | Space / 氮气按钮；有效漂移蓄满后松开获得 1 次，最多 3 次 |
| 道具 | E / 道具按钮；经过菱形补给拾取，最多携带 1 个 |
| 回正 | R；对应赛道位置回正并停顿 1.5 秒，不增加检查点 |
| 镜头 | C / 相机按钮；手机暂停菜单可切换 |
| 暂停 | P / Esc / 暂停按钮；窗口失焦或后台时自动暂停 |

涡轮补充氮气，护盾保护 8 秒，脉冲让前方 45 米内最近且没有护盾的对手减速。每圈需顺序通过 12 个检查点；超过 4 分钟为未完赛。成绩按赛车与难度在本机保存，只记录有效完赛。草地会减速，护栏和对手有碰撞。

声音在用户点击后初始化，可在暂停菜单关闭。可以全屏、重赛或换车；设计背景和完整玩法验证见 [赛车设计](design/racing.md)、[历史赛车验证](qa/racing-verification.md)。

## 星际穿行

进入 `/#games/starflight`，选择标准挑战（5 格护盾）或新手巡航（7 格护盾、较慢弹幕），点击「立即出击」。默认自动射击。穿越三重星区，必须击毁三阶段母舰才算通关。

| 操作 | 键盘 / 触屏 |
| --- | --- |
| 移动 | WASD / 方向键；鼠标或触屏按住战斗区拖动 |
| 手动射击 | 按住 Space / J；关闭自动射击后也可按住战斗区开火 |
| 自动射击开关 | F / 对应按钮 |
| 精细移动 | 按住 Shift |
| 冲击波 | X / B / 对应按钮；清除弹幕、短暂无敌、伤害敌舰 |
| 暂停 | P / Esc / 暂停按钮；窗口失焦或后台时自动暂停 |

机身中心光点是子弹碰撞判定位置。S 为散弹，L 为贯穿激光，M 为追踪导弹，+ 修复 1 格护盾，B 补充冲击波（最多 3 次）。同类武器最高三级，换装保留各自等级。连续击毁每 8 架提高一档倍率，最高 5 倍；受击或超过 3.8 秒没有击毁会中断。

第 90 秒母舰入场，光束轨道提前预警。音效与背景音乐可分别关闭，只在用户操作后初始化；全屏可用 Esc 或画面退出按钮返回。胜负后查看战报、重开或返回游戏库；游戏设置与记录只保存在当前浏览器。美术与战斗设计见 [战斗设计](design/combat.md)。

## 数据与故障

模型选择、分级、当前镜头和未完成游戏不是云端作品，刷新可能重置。已加入场景的实例、游戏偏好和记录使用本机存储；清除站点数据会删除它们。localhost 与线上域名不会共享记录。

如果三维视图启动失败，检查浏览器 WebGL / 硬件加速后使用重新加载。首次较大模型需要下载和解码；画布就绪前不要把空白判断为完成。全屏可能受浏览器或嵌入窗口限制，不支持时仍可在普通窗口使用。进一步排查见 [开发指南](DEVELOPMENT.md)。
