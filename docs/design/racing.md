# 湛蓝大奖赛 · AZURE CIRCUIT

原创开放轮式赛车与海滨街机赛道。沿用工作室的 React / Three.js 模型、场景、游戏共享方式。

- 模型：赤焰 R1、潮汐 R2、流星 R3。几何组成前后翼、轮胎/轮毂、双叉臂悬挂、侧箱、座舱、驾驶员、Halo。单位米，Y 向上，+Z 前进；可导出完整 GLB，车轮保留独立转向和旋转节点。
- 美术：晴空、青蓝海水、白色海岸建筑、橙白路肩、棕榈树、维修站与起终点拱门。车尾跟随镜头，赛道和对手优先；HUD 放四角。
- 比赛：玩家与五名 AI，完整封闭赛道，按顺序通过检查点完成三圈。倒计时、比赛、暂停、结果、重赛、换车与本机最佳成绩。
- 操作：方向键 / WASD；Shift 漂移；Space 氮气；E 道具；R 回正；C 镜头；P / Esc 暂停。默认自动油门，可在准备页切换手动。手机提供多指触屏按钮。
- 物理：独立固定时间步，真实平面位置、航向与速度，轮胎抓地与漂移惯性、草地减速、护栏和对手碰撞。AI 使用前视转向，在相同物理规则内跑圈。
- 氮气与道具：有效漂移蓄满后松开获得氮气；有限库存。赛道补给提供涡轮、护盾、脉冲，需按键实际使用。
- 数据：模拟状态独立于 React，DOM HUD 降频刷新。圈数由连续进度与有序检查点判定，不能靠回正/逆行刷圈。仅保存有效完赛时间，按车辆与难度区分。
- 验证：物理/检查点/漂移/道具/暂停/结束针对性测试；两档难度正常控制器完整模拟；真实浏览器键盘驾驶、手机按钮、完整跑圈、图像和控制台检查。

参考的是开放轮式赛车造型以及街机赛车的漂移、氮气与道具机制。车队涂装、车型名称和赛道均为本项目原创。
