# 星际穿行 · 战斗版本设计

[文档总览](../README.md) · [平台设计理念](overview.md) · [使用指南](../USER_GUIDE.md) · [测试指南](../TESTING.md)

本文聚焦纵向射击的玩法与美术设计；当前操作见使用指南，2026-09-05 的完整通关证据见 [专项验证记录](../qa/combat-verification.md)。早期生成提示保留为美术来源记录。

用户要求直接实现一个精细、完整、可玩的纵向射击游戏，参考《雷电》的敌我弹幕和道具换装逻辑。保留原来的模型、场景、游戏平台与探索者 01 身份。此版本为原创玩法、美术与音乐，不使用其他游戏的贴图、舰体或音轨。

机制参考：[NIS America 的 Raiden IV 武器介绍](https://www.nisamerica.com/blog/explore-the-explosive-arsenal-of-raiden-iv-x-mikado-remix)。仅借鉴直观的拾取换装、宽幅与集中火力取舍；本作自建追踪导弹与三阶段母舰。

## 美术与信息层级

- 原有石墨黑 / 象牙白 / 浅黄绿品牌。主战区采用深蓝色星球与破损轨道环，三段航程分别以蓝、暖褐、紫色轻微染色。
- 中央 13:18 纵向真实战场；桌面两侧提供任务航线、当前武装、补给说明、本机记录与快捷键。窄屏隐藏辅助栏，保留战场中必要的分数、护盾、暂停与冲击波。
- 敌弹红橙色实心外环与亮色内核，玩家散弹金色、激光青色、导弹紫色。敌弹不用模糊 bloom；玩家激光的外层透明度受限，避免遮盖敌弹。
- 敌舰使用原创有厚度的倒角装甲、分色翼板、进气格栅、发光座舱、引擎和炮口。母舰有翼塔、武器轴、六组推进器与中央反应堆。静态部件按材质合并几何，控制绘制调用。
- 探索者 01 复用模型库的 Rocket，加装后掠翼、机械炮管、推进组件。装饰陨石复用 Basalt，使用暗色版本并放在航道外侧。
- 环境画只有星空/星球/轨道遗迹；所有舰体、子弹、补给、爆炸与交互为实时 Three.js。所有文字和按钮为 HTML。
- 主菜单、开场星区提示、母舰预警、武器升级提示、暂停、失败与通关结算均有独立状态。非必要抖动响应 reduced-motion。

## 原创环境提示

为原创浏览器 3D 纵向街机飞行射击游戏《星际穿行 / STARFLIGHT》绘制一张可直接用作游戏底层背景的高品质太空环境美术。纵向 2:3 构图，尽可能高分辨率。镜头俯看深邃的午夜蓝宇宙，上半部偏右有一颗巨大深蓝星球的弧形边缘，细腻的大气层微光、云海，左上角一段极遥远的破损轨道环空间站，左下边缘有极克制的暗橙色星云余光和很暗的陨石轮廓。背景占据整个画面、没有边框。主体游戏空域留在整个中间与下部，整体深色低对比度、优雅冷静、结构细致，能够在上面清楚看到亮橙色敌军弹幕和青白色玩家子弹。精密电影概念美术、写实硬科幻材质、多层空间深度、微小星点、雾化光线，真实高质量游戏场景，不是平面矢量风，不要过曝。不要任何文字，不要 UI，不要按钮，不要图标，不要近景战斗机，不要子弹、不出现瞄准线或网格。原创视觉，与任何已存在游戏素材不同。

## 实现与视觉检查点

1. 参考环境的星球弧线和轨道环在实屏顶部清楚可见，下半部保留足够暗区，使敌弹可辨。
2. 黄绿主按钮和 STAR / FLIGHT 标題延续工作室品牌，背景不用图片替代 UI。
3. 开始后菜单离开中央空域，持续 HUD 只占顶部和底部；编队与弹幕的行动区域清楚。
4. 三种换装采用字母和不同颜色双重识别；当前武装、拾取反馈与子弹实际形态一致。
5. 桌面保留任务侧栏，手机使用完整宽度的纵向战场，真实拖动输入独立于按钮。

与环境画的有意差异：原始 2:3 画在 13:18 战区内轻裁切并压暗；加入微小星点、暗色真实陨石的独立滚动来建立视差。标题、机体与菜单由代码组合，并非把整张设计截图作为游戏。
